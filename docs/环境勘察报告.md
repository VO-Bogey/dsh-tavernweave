## 已核实的插件包格式（照 dgm-pkg / web-ui-all 反推）

```
my-plugin/
  package.json        # name, main: lib/index.js, exports ./client, dsh.client.{inject,platform:"web"}, peerDependencies 范围声明
  lib/index.js        # host: export const name/inject = ['tools',...]; export function apply(ctx){}
  lib/client.js       # client: window.__ModuleLoader__.load({ id, factory(require){ ... exports.apply/exports.inject } })
  cordis.patch.yml    # 仅 bundle 装配需要；运行时注入不需要
```

要点（来自注入器规范铁律）：
- 资源注册必须挂 `ctx.effect(() => {...})`，热重载/卸载才能自动清理
- peerDependencies 用范围：`cordis >=4.0.0-rc <5`、`@deepseek-ai/dsh-tools >=0.0.1-rc <2`
- client 里可用 `require("react")`；用 `React.createElement`，无 JSX
- client 插槽注册模式：`ctx.slots.inject("插槽名", () => ctx.slots.register({name, key, ...}, Component))`（见 dgm-pkg client）
- 宿主工具注册：`ctx.tools.register(defineTool({name, description, parameters, execute}))`
- 宿主 fs：`ctx.get('fs')`，`fs.resolve(path,{cwd})` / `fs.writeText`；sandbox：`ctx.get('sandboxPolicy')`
- 插件包必须自带依赖链接（node_modules 可解析到 peer 包）
