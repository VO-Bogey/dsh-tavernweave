## P0 · 已修复

### 1. React hooks 崩溃（用户报告：切页签面板消失、按钮消失）
- 根因：`UsageTab({ usage })`、`SkillsTab({ ... })` 是直接函数调用而非
  `react.createElement(Comp, props)`。切页签时 hooks 链断裂，React 抛错，
  DSH 槽位错误边界把整个插件撤下（面板+按钮全消失）。
- 修复：改为 createElement 渲染。
- 回归：五个页签往返切换、Esc、遮罩关闭全部通过，按钮不再消失。
