## 一、一句话说明

这是一个 **TavernWeave 制卡系统的 DeepSeek Harness（DSH）原生前端插件**。
即在 DSH 里挂一个「🍺 酒馆」面板，按阵营分层展示原作者使用口令速查、技能安装状态，
并规划资料库查询、角色卡工坊、模拟酒馆侧栏。**注意路线差异**：它不是 TW 官方
`host-adapters/dsh`（Skill loader 预设路线），而是 DSH 原生前端插件，两者互补。
